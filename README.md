# JS Tours - Travel and Car Rental Website 🌍🚗

Welcome to **JS Tours**, a modern travel and car rental website designed to help users explore beautiful destinations, plan their trips, and book transportation easily.

🌐 **Live Website**: [https://jstours.netlify.app/](https://jstours.netlify.app/)

## ✨ Features

- 🏞️ Tour and travel services
- 🚘 Car rental booking
- 📸 Attractive and responsive UI
- 🗺️ Location-based tour suggestions
- 🧳 User-friendly experience for travelers

## 🛠️ Tech Stack

- **HTML5** & **CSS3**
- **JavaScript**
- **Netlify** for deployment
